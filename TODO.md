# Modulane Roadmap

## Backend und Infrastruktur

1. ☑ Backend Architektur festlegen
2. ☑ API für Projekte, Features, Mitglieder und Updates entwickeln
3. ☐ Zentrale Fehlerbehandlung und Protokollierung einrichten
4. ☑ Entwicklungsumgebung konfigurieren
5. ☐ Automatisierte Tests für die wichtigsten Abläufe ergänzen

## Datenbank

1. ☑ Supabase anbinden
2. ☑ Datenmodell für Workspaces, Projekte, Features und Mitglieder erstellen
3. ☑ Status, Prioritäten, Anforderungen und Updates dauerhaft speichern
4. ☑ Rollen und Berechtigungen in der Datenbank abbilden
5. ☑ Beispieldaten durch echte Nutzerdaten ersetzen
6. ☑ Migration einrichten

## Anmeldung und Benutzerkonten

1. ☑ Registrierung und Anmeldung implementieren
2. ☑ Sitzungen sicher verwalten
3. ☑ Passwort zurücksetzen ermöglichen
4. ☑ Einladungen für neue Teammitglieder hinzufügen
5. ☑ Rollen wie Eigentümer, Administrator und Mitglied einführen
6. ☑ Benutzerprofile mit Name und Kontaktdaten ergänzen

## GitHub Integration

1. ☐ GitHub Anmeldung und Autorisierung einrichten
2. ☐ GitHub Organisationen und Repositories verbinden
3. ☐ Branches, Commits und Pull Requests abrufen
4. ☐ Pull Requests und Commits mit Features verknüpfen
5. ☐ Statusänderungen aus GitHub übernehmen
6. ☐ Webhooks für neue Commits und Pull Requests verarbeiten
7. ☐ Zugriffsrechte und erneute Autorisierung sauber behandeln

## Einstellungen

1. ☑ Workspace Einstellungen erstellen
2. ☑ Projekt Einstellungen hinzufügen
3. ☐ Eigene Statuswerte und Prioritäten konfigurierbar machen
4. ☑ Rollen und Berechtigungen verwalten
5. ☑ Benachrichtigungseinstellungen ergänzen
6. ☐ GitHub Verbindungen verwalten
7. ☐ Helles, dunkles und automatisches Design auswählbar machen

## Frontend Funktionen

1. ☑ Verbleibende Buttons mit echten Aktionen verbinden
2. ☑ Formulare an die API anbinden
3. ☑ Ladezustände, leere Zustände und Fehlermeldungen ergänzen
4. ☑ Projekte und Features bearbeiten und archivieren können
5. ☐ Kommentare und Erwähnungen in Updates ermöglichen
6. ☐ Benachrichtigungen als gelesen markieren
7. ☑ Globale Suche mit echten Daten verbinden
8. ☐ Filter und Ansichten pro Benutzer speichern
9. ☐ Tastatursteuerung weiter ausbauen

## Qualität und Veröffentlichung

1. ☐ Zugänglichkeit vollständig prüfen
2. ☐ Mobile Darstellung auf echten Geräten testen
3. ☐ Sicherheitsprüfung für Anmeldung und API durchführen
4. ☐ Leistungswerte messen und verbessern
5. ☐ Fehlerüberwachung und Nutzungsanalyse einrichten
6. ☐ Hosting und automatische Veröffentlichung konfigurieren
